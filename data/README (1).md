# Dataset

## Overview

The dataset used in this project consists of garment images annotated for hole detection, collected for Wärgon Innovation's quality control pipeline.

| Property | Details |
|---|---|
| **Original images** | ~380 (127 with holes, 253 without) |
| **After augmentation** | ~1,500 (750 with holes, 750 without) |
| **Annotation format** | COCO JSON (merged_annotations.json) |
| **Image type** | High-resolution garment photos |
| **Defect type** | 1–2mm holes |
| **Labels** | Single class: `hole` (category_id: 1) |

## Annotation Format

Annotations are in **COCO JSON** format:

```json
{
  "images": [{"id": 1, "file_name": "image_001.jpg", "width": 640, "height": 480}],
  "annotations": [{"id": 1, "image_id": 1, "category_id": 1, "bbox": [x, y, w, h]}],
  "categories": [{"id": 1, "name": "hole"}]
}
```

YOLO-format `.txt` files are generated automatically by `notebook 01`.
